# متابع فلتر المياه – نسخة محدثة للاختبار (5 ثوانٍ)

هذه نسخة مصدر معدلة انطلاقًا من V4 المرفوعة من المستخدم. ليست APK جاهزة ولم يتم اعتمادها نهائيًا.

## الإصلاحات في هذه النسخة
- معالجة اختيار الصور والملفات داخل Android WebView عبر WebChromeClient وفتح منتقي الملفات.
- تصدير النسخة الاحتياطية من أندرويد عبر نافذة حفظ ملف النظام، مع الاحتفاظ بمسار تنزيل المتصفح عند المعاينة.
- دعم استيراد JSON من منتقي الملفات.
- حفظ وقت التنبيه وأيام التذكير من الواجهة، وإعادة جدولة المنبهات.
- تنبيه في الأيام المحددة، وفي يوم الاستحقاق، وتنبيه متأخر يومي متكرر.
- أيقونة تطبيق مخصصة وأيقونة إشعار صغيرة أحادية اللون.
- تمييز صورة الشمعة التوضيحية بالألوان والوسم حسب الحالة.
- تسجيل تغيير الشمعة يستخدم السعر والمصنعية المحفوظين على بطاقة الشمعة تلقائيًا، ويربط المصروف بسجل التغيير لتجنب إعادة إدخاله يدويًا.
- ضغط الصور المرفوعة إلى حجم أصغر لتقليل استهلاك مساحة التخزين.
- دمج شاشة البداية واللوجو من أحدث معاينة محفوظة، مع حد أدنى لظهور شاشة اللودنج قدره 5 ثوانٍ، وعدم إخفائها قبل جاهزية الصفحة.

## الاختبار قبل اعتماد الإصدار
1. افتح `app/src/main/assets/index.html` في متصفح حديث لاختبار الواجهة والبيانات والمصاريف والسجل.
2. جرّب إضافة فلتر وتعديل شمعة وإضافة صورة ثم إعادة فتح الصفحة.
3. جرّب تصدير واستيراد JSON من المتصفح.
4. جرّب تسجيل تغيير جديد وتأكد أن السعر لا يتكرر تلقائيًا في المصروفات.
5. وظائف Android الأصلية (منتقي الملفات داخل WebView، حفظ الملف من نافذة النظام، الإشعارات بعد إغلاق التطبيق/إعادة التشغيل، وأيقونات المشغل والإشعار) لا يمكن اعتمادها من معاينة HTML؛ يلزم APK على هاتف فعلي.

## حالة التحقق
- تم فحص سلامة أرشيف ZIP.
- تم فحص صياغة JavaScript باستخدام `node --check`.
- تم تشغيل اختبارات متصفح آلية للواجهة: إضافة فلتر، تعديل شمعة، اختيار صورة ومعاينتها، إضافة مصروف، تسجيل تغيير، تصدير نسخة، وضبط حقول التنبيه؛ ولم تظهر أخطاء JavaScript في هذه الاختبارات.
- اختبار الاستيراد والتصدير عبر المتصفح تم على ملف JSON تجريبي.
- لم يتم تنفيذ Gradle/Android build في بيئة العمل الحالية لعدم توفر Android SDK وGradle. لذلك لا يوجد ادعاء بأن APK بُني أو أن الإشعارات اختُبرت على جهاز.

## مراجعة وإصلاحات 16 نوفمبر 2026
- إصلاح إلغاء المنبهات القديمة باستخدام بيانات الجدولة السابقة قبل حفظ القائمة الجديدة؛ لمنع بقاء تنبيهات لفلاتر أو مراحل تم حذفها أو استبدالها.
- إعادة بناء الجدولة عند فتح التطبيق وبعد إقلاع الجهاز أو تحديث التطبيق أو تغيير الوقت/المنطقة الزمنية.
- إضافة استعادة للتذكير الفائت بعد الإقلاع أو عند فتح التطبيق: إذا فات موعد تذكير أو استحقاق أثناء إغلاق الهاتف، يظهر إشعار استدراكي مرة واحدة لنفس موعد التذكير، مع استمرار التذكير اليومي للمرحلة المتأخرة.
- تحسين حساب أول تنبيه يومي متأخر حتى لا تمر حلقة طويلة على التواريخ القديمة.
- عند تسجيل تغيير الشمعة، يُسجل السعر والمصنعية المحفوظان على البطاقة تلقائيًا في سجل الصيانة والمصروفات، ويرتبط المصروف بسجل التغيير. حذف سجل التغيير يحذف المصروف المرتبط ويسترجع بيانات الشمعة السابقة عند حذف آخر تغيير.
- أضيف توضيح بجوار حقول السعر والمصنعية.

## نتائج التحقق في هذه المراجعة
- `unzip -t`: سليم.
- `node --check`: اجتاز فحص كتل JavaScript المضمنة.
- ملفات XML في Manifest وFileProvider والأيقونات: اجتازت التحليل.
- اختبار JavaScript مع بيانات تجريبية: اجتاز تسجيل السعر والمصنعية تلقائيًا، وربط المصروف بسجل التغيير، وحذف المصروف واسترجاع بيانات الشمعة السابقة.
- لم يتم بناء APK في بيئة المراجعة لعدم توفر Gradle وAndroid SDK، ولم يتم اختبار الإشعارات على هاتف فعلي. يلزم اختبار إعادة التشغيل على الهاتف، مع السماح بإشعارات التطبيق والتنبيهات الدقيقة إن رغبت في دقتها، والسماح بالتشغيل التلقائي/الخلفية من إعدادات Realme عند الحاجة.

## تعديل شاشة البداية عند الرجوع من الخلفية — 16 نوفمبر 2026
- شاشة اللودنج تظهر في التشغيل البارد فقط، أي عند فتح التطبيق من جديد بدون حالة Activity محفوظة.
- عند الرجوع إلى التطبيق من الخلفية، يحاول Android استعادة حالة WebView بدل تحميل صفحة جديدة.
- عند اضطرار Android لإعادة إنشاء Activity مع وجود حالة محفوظة، يتم إخفاء شاشة البداية قبل رسم الصفحة، حتى لا تظهر كأن التطبيق بدأ من الصفر.
- تمت إضافة حفظ واستعادة حالة WebView عبر `onSaveInstanceState` و`restoreState`.
- تم فحص كتل JavaScript وملفات XML وZIP بعد التعديل. لم يتم بناء APK لعدم توفر Android SDK وGradle في بيئة العمل.
